## Собственный проект

Тема проекта: каталог игр

Главный класс: `Game`

Почему этот объект нужен программе:
Класс `Game` хранит данные об одной игре в одном месте и не нужно заводить отдельные переменные для названия, жанра, года выхода и рейтинга каждой игры. Благодаря классу в каталог можно добавить сколько угодно игр и каждая будет хранить собственные данные.

Какие данные хранит объект:

- `Name (string)` - название игры.
- `Genre (string)` - жанр игры.
- `Release_date (int)` - год выхода игры.
- `Rating (int)` - рейтинг игры.

Какие значения задаются через конструктор:
- `Genre (string)` - жанр игры.
Название (Name), жанр (Genre) и год выхода (Release_date). Эти данные у каждой игры свои, поэтому передаются при создании объекта.

Какие значения можно задавать автоматически:
Рейтинг (Rating). Конструктор сам присваивает ему начальное значение 10, поэтому передавать рейтинг при создании передавать не нужно.
